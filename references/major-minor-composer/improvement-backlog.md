# 개선 백로그 — Major / Minor Composer

우선순위는 **음악 이론 정확성 > 오개념 방지 > 핵심 UX > 확장 기능** 순으로 정한다.

---

# P0 — 먼저 수정할 것

## P0-1. 조 이름 설명에서 시작 음 제거

현재 문제:
- 시작 음이 조를 결정하는 것처럼 읽힘

개선:
> 어떤 음을 으뜸음, 즉 음악의 중심으로 삼느냐에 따라 조가 달라진다.

효과:
- 조성 개념 오개념 방지

---

## P0-2. 화음 밖 음 = 잘못된 음 구조 완화

현재 문제:
- 화음 구성음이 아니면 지나치게 부정적으로 처리 가능
- G화음 위 F처럼 음악적으로 기능적인 긴장음도 존재

개선 분류:
- 안정적인 음
- 지나가는 음
- 긴장감을 만드는 음
- 다시 들어볼 음

효과:
- 창작 자유와 음악 정확성 개선

---

## P0-3. 자연단음계와 V화음의 올림7음 설명

현재 문제:
- 가단조 scale에는 G
- V chord에는 G#
- 학생에게 모순처럼 보일 수 있음

개선:
- V를 처음 선택할 때 한 줄 설명
- G# → A 해결 청음 제공

---

## P0-4. a/a′를 큰 형식과 구분

현재 문제:
- 각 마디의 유사성을 전체 곡 형식처럼 이해할 수 있음

개선:
> 마디가 서로 얼마나 닮았는지

또는:
> 가락 아이디어 관계

라는 설명 추가.

---

# P1 — 학습 효과를 크게 높이는 것

## P1-1. 오선보 view

grid 입력을 실제 오선보로 자동 변환.

효과:
- 계이름/음이름/음표 길이 연결
- 기초 기보와 직접 연결
- 인쇄 결과 품질 향상

---

## P1-2. 현재 리듬 길이 시각화

예:

~~~text
도 – – –
→ 4박 지속
~~~

학생이 –를 단순 빈칸으로 오해하지 않도록:

- sustain bar
- 음표 기호
- duration label

중 하나 제공.

---

## P1-3. Step 3 progressive reveal

초기:
- grid
- 처음부터
- 가락만

1마디 생성 후:
- 화음 피드백 강조

2마디 진입 후:
- 복사/변형 강조

목적:
- 인지부하 완화

---

## P1-4. 비교 청음

피드백에서:

- 현재 버전 듣기
- 추천 버전 듣기

를 나란히 제공.

텍스트 판정보다 학생의 청각적 판단을 우선한다.

---

## P1-5. 끝맺음 표현 완화

개선:
> 으뜸음으로 끝내면 가장 안정적으로 끝난 느낌이 나고, 다른 음은 열린 느낌을 만들 수 있다.

---

# P2 — 기능 확장

## P2-1. 리듬 해상도 확장

현재 1박 단위에서 선택적으로 1/2박 grid 제공.

처음부터 노출하지 않고 **리듬 더 자세히** 모드로 제공.

---

## P2-2. 셈여림/빠르기 실험

전체 곡을 복잡하게 편집하기보다:

- 두 가지 빠르기 비교
- 두 가지 셈여림 비교

부터 시작.

---

## P2-3. 작품 제출

학생:
- 제출하기

교사:
- 작품 모아보기
- 학생별 작품 확인
- 발표작 보기

접속은 링크/QR 방식 유지.

---

## P2-4. 버전 히스토리

현재 undo를 활용하여 주요 milestone 보관.

- 처음
- 수정 1
- 최종

학생이 자신의 변화 과정을 비교할 수 있게 한다.

---

# P3 — 심화

- 협력 작곡
- 자유 코드 진행
- 한 마디 안 화음 변화
- 8분음표/당김음

- MusicXML export
- 다양한 악기 음색
- 자유 형식

초기 초등용 UI에 바로 넣지 않는다.

# 반드시 유지할 것

개선 과정에서 다음 장점은 훼손하지 않는다.

- 4단계 구조
- 4마디 제한
- 곡 서랍
- 즉시 재생
- 복사/변형 버튼
- 우측 context help
- melodic contour
- 실제 피아노 연주 연결
- 로그인 없이 빠른 시작

기능 확장은 이 단순성을 해치지 않는 범위에서만 한다.
