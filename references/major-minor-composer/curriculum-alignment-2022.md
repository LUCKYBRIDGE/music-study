# 1. 관련 성취기준

## [6음03-01]

느낌과 아이디어를 다양한 매체와 방법으로 표현하는 창작 경험.

### 도구 연결

- 장조/단조 분위기 선택
- 디지털 grid를 통한 표현
- 여러 곡 제작과 비교

**정합성: 높음**

---

## [6음03-02]

기초 기보를 이해하고 조건에 따라 악곡의 일부를 바꾸는 활동.

### 도구 연결

- 마디 복사
- 끝음 바꾸기
- 위아래 뒤집기
- 음이름/계이름 사용

### 부족한 부분

실제 오선보나 전통적 기보와의 연결이 약하다.

**정합성: 중상**

실제 오선보 view가 추가되면 훨씬 직접적으로 연결될 수 있다.

---

## [6음03-03]

음악 요소의 의미와 효과를 활용하여 짧고 단순한 음악을 만드는 활동.

### 도구 연결

- 박/박자
- 장음계/단음계
- 주요3화음
- 가락
- 반복과 변화
- 디지털 매체
- 네 마디 창작

**정합성: 매우 높음**

이 도구의 핵심 성취기준으로 보는 것이 가장 적절하다.

---

## [6음03-04]

생활 주변 상황이나 이야기를 활용한 음악 만들기.

### 도구 연결

현재는 이야기/상황 입력이 거의 없다.

**정합성: 낮음**

현재 목적과 직접 연결하지 않아도 된다.

# 2. 5~6학년 음악 요소 매핑

| 음악 요소 | 현재 반영 | 분석 |
|---|---:|---|
| 박, 박자 | 높음 | 4/4, 4박 grid |
| 여러 가지 리듬꼴 | 낮음~중간 | 1박 해상도 duration은 가능하나 세분 부족 |
| 음이름, 계이름 | 높음 | 둘 다 표기 |
| 장음계, 단음계 | 매우 높음 | 핵심 학습 내용 |
| 주요 3화음 | 매우 높음 | I/IV/V 직접 선택 |
| 다양한 소리의 어울림 | 높음 | 화음/가락 관계 |
| 형식 | 중간 | a/a′ 패턴은 있으나 큰 형식과 구분 필요 |
| 셈여림 변화 | 낮음 | 사실상 없음 |
| 빠르기 변화 | 낮음 | 느리게 기능은 있으나 음악적 변화 표현은 아님 |
| 음색 | 낮음 | 선택/비교 기능 제한 |

# 3. 기초 기보와의 거리

현재 시스템은 계이름/음이름과 시간 grid를 사용한다.

이는 창작 자체에는 좋지만 교육과정의 **기초 기보 이해**와 완전히 동일하지는 않다.

따라서 다음 bridge가 필요하다.

~~~text
grid
→ duration/계이름
→ 오선보
~~~

학생이 입력한 것이 실제로:

- 온음표
- 2분음표
- 점2분음표
- 4분음표

중 무엇에 해당하는지 자동 변환해 보여 주면 [6음03-02]와의 연결이 크게 강화된다.

---

# 4. 창작 과정 평가와의 연결

2022 개정 교육과정은 창작 결과만이 아니라 **과정과 참여**도 함께 살피는 방향을 제시한다.

현재 곡 서랍과 undo/history 구조를 확장하면 다음 데이터를 만들 수 있다.

- 최초 아이디어
- 수정 횟수
- 반복/변형 사용 여부
- 여러 버전 비교
- 발표곡 선택 이유
- 최종 성찰

교사용으로는 점수화보다 과정 기록을 요약하는 것이 더 적합하다.

---

# 5. 추천 학습목표

이 도구를 활용하는 한 차시/프로젝트 목표는 지나치게 넓히지 않는 것이 좋다.

예:

> 장음계와 단음계의 느낌을 비교하고, 주요 3화음과 가락의 어울림을 생각하며 네 마디의 간단한 음악을 만들 수 있다.

또는:

> 반복과 변화를 활용하여 네 마디 가락을 만들고, 만든 음악의 특징을 설명할 수 있다.

---

# 6. 추천 평가 관점

## 지식·이해

- 선택한 조의 음계를 이해하는가
- 주요 3화음의 구성음을 구분하는가

## 과정·기능

- 반복과 변화를 활용했는가
- 듣고 수정하는 과정을 거쳤는가
- 가락과 화음의 관계를 고려했는가

## 가치·태도

- 여러 가능성을 시도하는가
- 자신의 곡을 설명하고 공유하는가
- 친구의 다른 선택을 열린 태도로 듣는가

---

# 7. 도구에 추가하면 교육과정 연결이 좋아지는 기능

1. grid → 오선보 자동 변환
2. 리듬 subdivision 선택
3. 셈여림 한 단계 변화
4. 빠르기 변화 실험
5. 발표곡 선택 이유 한 문장 기록
6. 친구 곡 비교 듣기
7. 간단한 창작 일지/변경 기록

모든 기능을 한 화면에 넣는 것은 권장하지 않는다. 단계별 확장 기능으로 분리한다.
