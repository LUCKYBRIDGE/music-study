# Pattern — Guided Composition

여러 음악 교육 웹에서 재사용할 수 있는 **단계형 작곡(guided composition)** 패턴을 정리한다.

## 문제

초등학생에게 빈 악보나 완전한 자유 작곡 화면만 제공하면 다음 문제가 생긴다.

- 어디서 시작해야 할지 모름
- 음악 개념보다 UI 조작에 에너지를 씀
- 너무 많은 선택지 때문에 무작위 입력이 늘어남
- 결과를 어떻게 수정해야 하는지 모름
- “완성”의 기준이 없음

## 해결 원리

자유도를 없애는 것이 아니라 **시점별로 필요한 선택지만 공개**한다.

```text
듣기
 ↓
큰 방향 선택
 ↓
재료 선택
 ↓
짧은 단위 만들기
 ↓
복사/변형
 ↓
들어보기
 ↓
피드백
 ↓
수정
 ↓
비교/선택/발표
```

## 추천 단계

### 1. Listen

먼저 예시를 듣는다.

텍스트 설명만으로 시작하지 않는다.

### 2. Choose

학생이 큰 음악적 방향을 선택한다.

예:

- 장조 / 단조
- 빠르게 / 느리게
- 일정한 리듬 / 변화 있는 리듬

### 3. Constrain

사용 가능한 재료를 제한한다.

예:

- 특정 음계
- 한 옥타브
- 4마디
- 마디당 4박
- I·IV·V 화음

### 4. Seed

첫 단위를 직접 만든다.

작곡소 예:

> 1마디 — 씨앗 심기

### 5. Transform

창작 개념을 버튼으로 제공한다.

- 복사
- 한 음 바꾸기
- 끝음 바꾸기
- 위아래 뒤집기
- 리듬 늘이기/줄이기
- 반복 횟수 바꾸기

### 6. Compare

변경 전/후를 바로 들어본다.

### 7. Explain

시스템은 “틀렸다”보다 **왜 다르게 들리는지** 설명한다.

### 8. Reflect

여러 작품이나 버전을 비교하게 한다.

### 9. Publish

발표/인쇄/제출/공유로 마친다.

## UI 원칙

### One decision at a time

한 화면에서 선택해야 할 핵심 질문은 가능하면 하나로 제한한다.

### Immediate audition

선택 옆에 항상 듣기 버튼을 둔다.

### Reversible actions

- undo
- redo
- 초기화
- 예시 복원

을 제공한다.

### Transformation over blank creation

“새로 만들어라”보다:

- 복사하고 바꿔 보기
- 끝만 바꿔 보기
- 방향을 뒤집어 보기

가 초등학생에게 훨씬 효과적이다.

### Show cause and effect

학생의 행동 직후:

- 시각 변화
- 소리 변화
- 간단한 설명

이 동시에 나타나야 한다.

## 음악 데이터와 UI 분리

Guided UI는 제한적이어도 내부 데이터 구조까지 제한적이면 안 된다.

예:

```text
학생 UI: 한 박에 한 음
내부 모델: pitch + onset + duration
```

이렇게 해야 이후 8분음표, 쉼표, 붙임줄 등으로 확장할 수 있다.

## 피드백 패턴

나쁜 방식:

> 틀렸습니다.

권장:

```text
2마디 3박의 솔은 지금 화음에는 없는 음이야.
그대로 들어볼 수도 있고,
파로 바꾸면 화음과 더 안정적으로 어울려.
[현재 듣기] [추천 듣기]
```

핵심:

- 위치
- 현재 상태
- 이유
- 대안
- 비교 청음

을 한 묶음으로 제공한다.

---

## 초등 음악에 적합한 제한

작곡 입문 단계에서는 다음 정도가 적절하다.

- 4마디
- 4/4박자
- 5~8개 음
- 1옥타브 전후
- 1·4·5도 화음
- 한 번에 하나의 리듬 개념
- 최대 2~4개의 작품 슬롯

기능을 늘리기보다 한 개념을 반복해서 듣고 수정할 수 있게 하는 편이 중요하다.

---

## 언제 쓰지 말아야 하는가

Guided composition은 모든 창작 단계에 적합하지 않다.

다음 단계에서는 자유 모드가 필요하다.

- 이미 기본 작곡 경험이 있는 학생
- 실험적 소리 만들기
- 자유 형식
- 다양한 박자
- 다성부
- 코드 진행 직접 설계

따라서 최종 서비스는:

```text
도움받아 만들기
자유롭게 만들기
```

두 모드를 분리하는 방식이 적합하다.
